## Мой скрипт: Генератор координат для портала в Незер
Скрипт берет координаты из обычного мира и рассчитывает точную точку для постройки ответного портала в Нижнем мире (делит координаты X и Z на 8).

```python
x = int(input())
z = int(input())
nether_x = x // 8
nether_z = z // 8
print(f"Nether gates at X: {nether_x}, Z: {nether_z}")
```
